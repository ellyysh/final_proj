# PokéJournal

PokéJournal это личный журнал тренера покемонов для Android. Каталог берётся из открытого PokeAPI, а отметки, заметки, коллекции и история хранятся на устройстве.

Стек: Kotlin, Jetpack Compose, Material 3, Navigation Compose, Hilt, Retrofit, Room, DataStore, Coroutines и Flow, WorkManager, Coil.

## Что добавлено в финальной работе

Базовая часть из прошлых домашних заданий сохранена: список с поиском, экран деталей, загрузка из сети, Room, Hilt и состояния загрузки, ошибки и пустого результата. Поверх неё появились:

- фильтры по типу и личному статусу, сохранённые фильтры, закреплённые покемоны наверху списка;
- личный статус, заметка, закрепление и скрытие в карточке покемона;
- пользовательские коллекции с загрузкой для просмотра без интернета;
- история просмотров;
- локальные профили с прогрессом по пойманным покемонам и списком заметок;
- экран настроек;
- работа без интернета и фоновая синхронизация.

## Новые пользовательские данные

Все данные хранятся в Room и привязаны к профилю. При удалении профиля удаляются и все его данные.

- **profiles**: локальные профили. Профиль по умолчанию создаётся при первом запуске.
- **pokemon_user_state**: статус покемона (видел, хочу, поймал), закрепление и скрытие.
- **notes**: заметки о покемонах.
- **collections** и **collection_items**: коллекции и их состав (связь многие ко многим, без дублей).
- **history**: история просмотров, уникальная по покемону и ограниченная лимитом.
- **filter_presets**: сохранённые фильтры.

Отдельно хранится кэш данных из API, общий для всех профилей. DataStore используется только для настроек: активный профиль, настройки профиля и параметры синхронизации.

## Новые сценарии

1. **Коллекции для офлайна.** Создать коллекцию, добавить в неё покемонов и нажать «Скачать для офлайна». Приложение загружает карточки в фоне и показывает прогресс, после чего коллекция открывается без интернета.
2. **Личный журнал.** Отметить статус, закрепить, скрыть покемона или написать заметку. Каталог и прогресс в профиле обновляются сразу.
3. **Профили.** Создать второго тренера с пустым журналом и своими настройками. Переключение сразу меняет все экраны, удаление профиля удаляет его данные.
4. **Сохранённые фильтры.** Настроить поиск, тип и статус и сохранить их. Фильтр появляется чипом и применяется одним нажатием.
5. **История просмотров** с лимитом, который задаётся в настройках профиля.

## Как устроена offline-first часть

- Экраны читают данные только из Room, сеть лишь обновляет локальную копию.
- Данные обновляются, если устарели по времени жизни кэша из настроек, при ручном обновлении или при расширении Pokédex.
- Если сети нет, но данные сохранены, показывается список и предупреждение об отсутствии связи. Ошибка показывается, только когда сохранённых данных нет.
- Каталог и детали хранятся раздельно, поэтому обновление каталога не стирает загруженные карточки.
- При появлении сети обновление запускается автоматически.
- Заранее подгружаются карточки из коллекций, со статусом, закреплённые, с заметками и из истории.
- Картинки кэшируются средствами Coil.

## Фоновая обработка

Для фоновой работы используется WorkManager.

- **CatalogSyncWorker (периодический)** запускается раз в 6, 12 или 24 часа при наличии сети (или только по Wi-Fi) и нормальном заряде. Обновляет каталог и подгружает важные карточки. При ошибке сети повторяет попытку, после трёх неудач завершается.
- **CatalogSyncWorker (разовый)** запускается кнопкой «Синхронизировать сейчас» в настройках, там же виден его статус.
- **CollectionDownloadWorker** загружает все карточки коллекции и передаёт прогресс на экран.

При изменении настроек синхронизации периодическая задача перепланируется автоматически.

## Тесты

Все тесты лежат в `app/src/test` и запускаются без эмулятора.

**Юнит-тесты:**
- CachePolicyTest: проверка срока жизни кэша;
- PokemonListBuilderTest: поиск, фильтры, скрытые, закреплённые и сортировка;
- NameValidatorTest, StatsCalculatorTest, MappersTest: валидация названий, подсчёт прогресса, преобразование данных из API;
- PokemonListViewModelTest: последовательность состояний, повтор после ошибки, работа с кэшем без сети, debounce поиска, отмена устаревших запросов, обновление списка при изменениях в журнале;
- PokemonDetailViewModelTest: загрузка карточки, запись в историю, повтор после ошибки, разделение данных по профилям, создание коллекций;
- OfflineSyncTest: логика синхронизации и загрузки коллекций.

**Интеграционные тесты:**
- PokemonRepositoryIntegrationTest: репозиторий вместе с Room и тестовым API, сохранение данных при ошибке сети;
- UserDataIntegrationTest: коллекции, история, профили и каскадное удаление;
- WorkerIntegrationTest: работа воркеров, повтор при отсутствии сети, загрузка коллекции для офлайна;
- PokemonListUiTest: переход на нужную карточку, кнопка повтора и путь от ошибки к списку.
