# PokéJournal

PokéJournal это личный журнал тренера покемонов для Android. Список покемонов берётся из открытого PokeAPI, а отметки, заметки и коллекции хранятся на устройстве.

## Возможности

**Pokédex.** Поиск по имени или номеру, фильтры по типу и статусу, сохранённые фильтры.

**Карточка покемона.** Статус «Поймал», «Хочу» или «Видел», заметка, закрепление и скрытие, добавление в коллекцию.

**Коллекции.** Свои списки покемонов, которые можно скачать для просмотра без интернета.

**История.** Недавно открытые карточки с настраиваемым лимитом.

**Профили.** Несколько тренеров на одном устройстве, у каждого свой журнал, коллекции, история и настройки. В профиле виден прогресс по пойманным покемонам и все заметки.

**Настройки.** Сортировка, регион Pokédex, тема, частота фонового обновления и обновление только по Wi-Fi.

## Работа без интернета

Загруженные данные сохраняются на устройстве, поэтому без сети приложение показывает сохранённую информацию. После восстановления связи данные обновляются автоматически. Карточки из коллекций, закреплённые, с заметками и из истории подгружаются заранее в фоне.

## Технологии

Kotlin, Jetpack Compose, Material 3, Hilt, Retrofit, Room, DataStore, Coroutines и Flow, WorkManager, Coil.
